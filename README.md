# CAMEL-SMSC-Interfacing
This repository contain a very basic minimal implementatino of CAMEL protocols and then we have a dummy/fake/simulator SMSC server whic is interacting with CAMEL server. 
First run CAMEL then tune SMSC and in log, one can see that connection is established. 
Now to see if after connection the interface are exchanging the information , we created a dummy web page to simulate a mobile device from where one can send a SMS from 1 number to other
Once you submit a message from this simulator, then one can see logs of CAMEL showing that msg request recived and response sent. 

A word document is present in zip file to see screenshot of system in run.
